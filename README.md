## About

くもたんは、Bluesky のタイムラインから英単語を登録して、自分だけの単語帳を作る英語学習アプリです。iPhone 版を公開中で、Web 版を準備しています。

- App Store: <https://apps.apple.com/jp/app/id6757349745>
